## Known limits (say them, don't hide them)

- **Battery runtime is not measured:** no Li-Po fitted yet, and the fuel gauge has not arrived. Recommendation for further study.
- The **signal-vs-distance fit** (Test 1, 21 Sep) is poor: n = 0.55, R² = 0.30. Indoor multipath makes distance unreliable, which is why zones are decided by the **strongest beacon**, not by distance.
- **Test 2 Run 1** (24 Sep, older proximity firmware, low-power profile) scored 56.2 %. Run 3 today is the configuration being demonstrated.
