# Project Instructions — Indoor Elderly Localization System

**Course:** Electronics Design, BS ECE, Mapua University. Requires a working PCB prototype defended before a panel in Week 9, plus an IEEE-format paper and a user manual.

**Core function:** wearable determines zone via BLE scanning of fixed beacons; door sensors alert on restricted-area entry; web dashboard shows location, status, alerts in real time.

Full in-scope/out-of-scope list, hardware baseline, adviser priorities, known risks: see [[Decisions Log]], [[Open Questions]], [[Hardware BOM - Wearable]], [[Hardware BOM - Door Sensor]].

## How to help (standing guidance for this project)

- Be direct about problems — if a design choice won't survive the panel, say so.
- Distinguish settled decisions ([[Decisions Log]]) from open ones ([[Open Questions]]).
- Flag anything needing adviser sign-off rather than deciding unilaterally.
- Prefer concrete numbers (current draw, runtime, RSSI, latency) over vague claims.
- Cite real sources for Chapter 2 / problem statement — never fabricate statistics or references.
- Document output in formal academic English; Taglish fine in conversation.
